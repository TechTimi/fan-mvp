# Fan MVP

A React Native/Expo mobile application MVP.

## Getting Started

This project uses Expo for React Native development.

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn
- Expo CLI

### Installation

```bash
npm install
# or
yarn install
```

### Running the App

```bash
npm start
# or
yarn start
```
